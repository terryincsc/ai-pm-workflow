# 規劃書 (plans)

每次新需求,PM 在動工前會在這裡放一份規劃書。

## 檔名規則

```
NNN_YYYY-MM-DD_大綱.md
```

- `NNN` — 第幾次需求,補零到三位(001、002…)。取現有最大編號 +1;空資料夾從 001 起。
- `YYYY-MM-DD` — 當天日期(PM 先跑 `date +%F` 查證,不要用猜的)。
- `大綱` — 這次改動的簡短標題,用底線或短橫連接,不要空格。

例:`003_2026-07-07_加入登入功能.md`

編號放最前面是為了讓檔案總管 / `ls` 能照需求順序排列。

## 一份規劃書包含
1. 這次要做什麼(逐條)
2. 範圍界線:可動 / 不碰
3. 驗收標準
4. 風險與對策
5. 實作方向、RD 任務拆分、角色與模型、允許檔案及驗證方式
6. 結尾狀態:PR 前標記「✅ 實作與驗證完成，待合併」，合併狀態以 PR 為準
